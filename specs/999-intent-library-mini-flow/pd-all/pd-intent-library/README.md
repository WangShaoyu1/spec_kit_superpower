# pd-intent-library: 指令库管理最小闭环示例

## 范围

本示例只覆盖指令库管理的最小闭环：

1. 新建指令库
2. 新建训练数据集
3. 在数据集中维护最小意图数据
4. 基于训练集创建模型草稿

## 页面清单

| 页面 | 作用 | 说明 |
|------|------|------|
| `index.html` | 指令库列表页 | 支持新建指令库、查看统计、进入详情 |
| `detail.html` | 指令库详情页 | 展示基础信息、模型草稿、绑定训练集 |
| `datasets.html` | 数据集列表页 | 创建训练数据集，跳转数据管理 |
| `dataset-detail.html` | 数据集详情页 | 维护意图、相似问、词槽引用 |
