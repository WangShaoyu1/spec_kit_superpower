# 用户管理页面表格列宽分配不合理，表头和内容逐字竖排

## 现象
`/user-manager` 页面 Table 中「最后登录」「创建时间」列过窄，导致：
- 列头文字逐字竖排显示（如"最\n后\n登\n录"）
- 日期数据 `2026-03-19 11:19` 逐字符换行，完全不可读
- 用户名 `roleuser_08496401` 严重换行

## 期望
- 表格列宽合理分配，所有列头横向单行显示
- 日期、用户名等内容不因列宽过窄而逐字换行
- 必要时使用 `scroll={{ x: true }}` 或为关键列设置 `minWidth`

## 复现步骤
1. 登录后导航到 `/user-manager`
2. 查看用户列表表格
3. 观察「最后登录」「创建时间」列的显示效果

## 根因
Table 未设置 `scroll.x` 最小宽度，列宽在窄容器内被挤压，导致列头和内容逐字换行。

## 修复方案
为 Table 设置 `scroll={{ x: 1150 }}` 强制最小表宽，确保列宽不因容器收缩而失真。

## 修复说明
在 UsersTab 的 Table 组件上设置 `scroll={{ x: 1150 }}`（列宽之和约 1070，略有余量），保证「最后登录」「创建时间」等列横向单行显示。

## 设计回溯
无设计文档不一致。实现层布局调整。
