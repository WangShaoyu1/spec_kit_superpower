# 指令库模块与 PD 交互稿存在多处功能差距

## 现象（持续对照 PD）
原表格见下历史记录；此外复测反馈：

1. **信息架构**：PD 中「数据集管理」为**指令库管理下的子菜单**，实现曾仅在详情/嵌套路由下可达，侧栏无对应子项。
2. **LLM 合成**：弹窗确认后仍提示「演示」类文案，易误解为已排队任务；**后台无合成 API / Worker**，属规格外未实现能力。
3. **开始训练 500**：`POST /api/v1/models/{id}/train` 在异步 SQLAlchemy 下，`updated_at` 在 UPDATE 后过期，序列化响应时隐式 IO 触发 `MissingGreenlet`，浏览器表现为 **500**（非业务码）。

其它 PD 差项（统计卡、状态列、测试页完整能力、G6 状态机等）仍可能未完全关闭，需继续按 PD 清单验收。

## 期望
- PD 所列 UI/流程与实现一致；关键链路（建库 → 数据集 → 模型版本 → 训练）可跑通且无伪成功提示。
- 未实现能力须**明确告知**用户，而非「演示已成功」类 copy。

## 复现步骤
1. 侧栏：此前无「指令库管理 → 数据集管理」子菜单（已补枢纽页 `/dataset-management`，见修复说明）。
2. 数据集页 LLM 合成：点击确定，曾出现「演示」成功提示（已改为明确未接入说明）。
3. 详情页新建模型版本后「开始训练」：曾返回 HTTP 500（已修 `refresh`）。

## 根因（训练 500）
`TimestampMixin.updated_at` 带 `onupdate`；`UPDATE library_model_versions` 后 ORM 属性过期。`AsyncSession` 中在 `_model_to_dict` 读取 `updated_at` 会触发隐式同步 IO → **`sqlalchemy.exc.MissingGreenlet`** → 未被业务异常包装 → **500**。

## 根因（LLM / PD 差距）
- 合成：无 `py` 侧 `synthesis` 路由与任务表，前端原为占位成功 Toast。
- IA：路由长期只有 `/intent-library/.../datasets`，与 PD「指令库管理 → 数据集管理」子菜单不一致。
- 测试策略：集成测试未覆盖 `POST .../train` 等关键写路径，导致异步 ORM 回归未被发现。

## 修复方案（本轮已做）
1. **后端**：在 `model_version_service` 中凡 `flush` 后需返回 ORM 转 dict 的更新路径，增加 `await db.refresh(...)`（含 `start_training`、完成训练、评测、发布、归档、恢复、`testable` 等）。
2. **测试**：`tests/integration/test_intent_library_flow.py` 增加 `test_start_training_model_version`，锁住训练入参与 PD 前端一致。
3. **前端 IA**：新增 `/dataset-management` 枢纽页 + 侧栏 **指令库管理** 下子项「数据集管理」；`/intent-library/:id/datasets` 高亮与该子项一致。
4. **LLM 文案**：取消「演示已成功」；改为 `message.warning` 明确未接入服务端。

## 仍待产品/迭代（非本轮代码可一次性关闭）
- 全站 **LLM 合成** 需 AD：任务创建 API、队列、与 `TrainingDataset` 写入对接。
- PD 中 **模型测试**、**批量测试**、**G6 状态机** 等仍以 `Placeholder` 或简版实现为主时，应拆子任务或继续本 D031 分阶段验收。
- **测试策略补充**：建议在 `specs`/CI 中增加「指令库闭环」清单：`创建库 → 数据集 CRUD → 创建模型版本 → train →（可选）evaluate → publish`，至少集成或 E2E 覆盖写路径。

## 修复说明（2026-03-20 增量）
- 训练 500：`model_version_service.py` + 集成测试。
- 数据集入口 + 侧栏子菜单（指令库管理 → 数据集管理）：`DatasetManagement/index.jsx`、`App.jsx`、`MainLayout.jsx`。
- LLM 提示：`Placeholder.jsx`。

## 设计回溯
- DD 状态机与 API 本身合理；**缺口在异步 ORM 使用约定**（flush 后刷新再读列）与 **PD 级能力（合成、测试）未落到 AD/任务**。
- 无需改 DD 枚举；建议在 `dd-intent-library` 或测试计划中显式写入「训练接口集成测试必跑」。
