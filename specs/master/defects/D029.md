# 顶部 Header 用户名显示不一致：部分页面显示"用户"而非实际用户名

## 现象
- 登录后首次进入 `/intent-library` 页面，Header 右上角显示 `admin`
- 通过浏览器地址栏直接导航到其他页面后，Header 显示 `用户`（通用 fallback）而非 `admin`

## 期望
Header 右上角始终显示当前登录用户的用户名或姓名（如 `admin`），不应出现通用 fallback 文案。

## 复现步骤
1. 登录 admin 账号
2. 进入指令库页面，观察右上角用户名（显示 `admin`）
3. 在地址栏输入 `/knowledge-base` 并回车
4. 观察右上角用户名（变为 `用户`）

## 根因
直接导航（地址栏输入 URL）时，MainLayout 挂载时 auth store 的 user 仍为 null（login 后 user 仅在一次 store 更新中写入，reload 后 token 在 localStorage 但 user 未从 /auth/me 拉取）。

## 修复方案
MainLayout 挂载时，若 token 存在且 user 为空，则调用 loadUser() 从 /auth/me 拉取用户信息。

## 修复说明
在 MainLayout 中增加 useEffect：当 token 存在且 user 为 null 时调用 loadUser()，确保直接导航到任意页面时 Header 能显示正确用户名。

## 设计回溯
无设计文档不一致。dd-user-mgmt §5 已定义用户信息展示。
