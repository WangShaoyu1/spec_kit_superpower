# 指令库管理菜单，里面缺少指令集管理、指令批量测试、单条测试

## 现象
1、目前实现的指令库管理模块，内部缺少很多的页面、逻辑，和设计稿 pd-all/pd-intent-library中的定义，完全对不上，忽略了核心逻辑


## 期望
1、严格补齐 `pd-intent-library` 定义的 5 个页面边界：列表、详情、数据集、数据集详情、测试页。
2、恢复 `指令库列表 -> 详情 -> 数据集 -> 数据集详情 -> 测试页` 的主流程。
3、`测试页` 必须同时承接 `单条测试` 和 `指令库内批量评估`，不能错误跳去别的模块。

## 复现步骤
1、登录后台，进入 `指令库管理`。
2、检查菜单内页面与跳转链路。
3、可以看到只有一个聚合页，缺少 `数据集管理 / 数据集详情 / 模型测试` 等独立页面，和 PD 明显不一致。

## 根因
1、实现阶段将 `pd-intent-library` 的多页面信息架构错误压扁成了一个 `IntentLibraryPage` 单页聚合实现。
2、前端路由只保留了 `/intent-library`，没有为 `detail / datasets / dataset-detail / test` 建立独立路由与返回链路。
3、后端只暴露了库详情摘要接口，没有为 `dataset-detail` 页面提供独立的数据集样本明细接口。

## 修复方案
1、前端按 PD 边界重拆路由与页面，恢复 5 页结构。
2、侧边栏保持 `指令库管理` 高亮覆盖全部 `/intent-library/**` 子路由。
3、测试页拆分为 `单条测试` 与 `批量测试` 两个 Tab，并直接展示评估分析结果。
4、后端新增 `dataset-detail` 所需的数据集详情接口，返回数据集元信息与样本明细。
