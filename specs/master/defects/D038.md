# 指令库详情，有一个字段 key 和 value 都不显示

## 现象
详情页基础信息区第三列对应行：标签为空白（仅空格）、值为占位 `-`，接口已返回 `default_intent_f1_threshold` 但未展示。

## 期望
与后端 `LibraryResponse` 一致展示「意图 F1 阈值」及数值（与「置信度阈值」「模糊阈值」并列）。

## 复现步骤
1. 打开任意指令库详情 `/intent-library/:id`
2. 观察「置信度阈值」「模糊阈值」右侧一行：标签几乎不可见、值为 `-`

## 根因
`Detail.jsx` 使用 `<Descriptions.Item label=" ">` + `-` 作为栅格占位，未绑定 `default_intent_f1_threshold`；Store 的 `fetchLibraryDetail` 也未映射该字段到统一展示名。

## 修复前端
1. 将占位项改为 **意图 F1 阈值**，展示 `intent_f1_threshold`（由 store 从 `default_intent_f1_threshold` 映射）。
2. `intentLibraryStore.fetchLibraryDetail` 增加 `intent_f1_threshold` 映射，与 D023 列表字段映射方式一致。

## 修复说明
见 `fix_ref`；设计文档无需改，API 已包含该字段。

## 设计回溯
代码未对齐已有 API/DD 字段，属实现遗漏，非 AD/DD 矛盾。
