# 监控子页面 Table 空状态显示英文"No data"，与全站中文风格不一致

## 现象
- `/monitoring/device-logs` 页面 Table 空状态显示英文 `No data`
- `/monitoring/alert-rules` 页面告警规则表和告警事件表空状态均显示英文 `No data`
- 其他页面（知识库、批量测试等）正确显示中文空状态如「暂无文档」「暂无批量测试」

## 期望
所有 Table 空状态统一使用中文，如「暂无数据」「暂无日志」「暂无告警规则」。

## 复现步骤
1. 登录后导航到 `/monitoring/device-logs`，在无数据时观察 Table 空状态文案
2. 导航到 `/monitoring/alert-rules`，观察两个表格的空状态文案

## 根因
DeviceLogs、AlertRules 页面的 Table 未设置 `locale.emptyText`，使用了 Ant Design 默认英文「No data」。

## 修复方案
为两页面的 Table 增加 `locale={{ emptyText: '暂无日志' }}` 和 `locale={{ emptyText: '暂无告警规则' }}` / `locale={{ emptyText: '暂无告警事件' }}`。

## 修复说明
- DeviceLogs: Table 增加 `locale={{ emptyText: '暂无日志' }}`
- AlertRules: 告警规则表 `locale={{ emptyText: '暂无告警规则' }}`，告警事件表 `locale={{ emptyText: '暂无告警事件' }}`

## 设计回溯
无设计文档不一致。
