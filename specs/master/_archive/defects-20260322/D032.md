# 知识库模块与 PD 交互稿存在多处功能差距

## 现象
对照 `pd-knowledge-base/` 的 index 和 detail 页面，实际存在以下差距：

### 列表页 `/knowledge-base`
| PD 定义 | 实际 | 差距 |
|---------|------|------|
| 「检索测试」按钮 | 不存在 | 缺失 |
| 统计卡: 分类总数/文档总数/已索引/索引中 | 不存在 | 缺失 |
| Table 列: 有效字段/总字段 | 不存在 | 缺失 |
| 格式筛选器(json/markdown/txt) | 不存在 | 缺失 |
| 重置按钮 | 不存在 | 缺失 |
| 分类卡片编辑/删除操作 | 无数据无法验证 | 待确认 |

### 详情页 `/knowledge-base/:id`
PD 定义了文档详情页，包含：
- 基本信息（文档名称、所属分类、格式、大小、状态、上传/索引时间）
- 字段解析（有效字段表、无效字段表）
- 索引内容预览
- 检索测试区（匹配得分、匹配内容）
- 重新索引、删除文档操作

无数据状态下无法验证详情页完整性，但需确认上述功能在有数据时是否完整实现。

## 期望
实现 PD 中定义的检索测试入口、统计卡片、格式筛选、有效字段列等功能。

## 复现步骤
1. 登录后进入 `/knowledge-base`
2. 对照 PD 检查按钮、统计卡、筛选器
3. 确认缺失项

## 根因
同 D031，AD/DD 未覆盖前端统计卡、筛选器等 UI 规格。

## 修复方案
新增统计卡（分类总数/文档总数/已索引/索引中）、格式筛选器、重置按钮、检索测试按钮及弹窗。

## 修复说明
KnowledgeBase/index.jsx: 新增 4 个统计卡、格式筛选器 Select、重置按钮、检索测试 Modal。

## 设计回溯
同 D031，DD 缺少前端 UI 组件清单。
