# 接口响应格式不统一

## 现象
接口响应格式不统一，未采用约定的 code/data/msg 结构。

## 期望
接口响应保持如下格式：
```json
{
  "code": "000000",
  "data": xxx,
  "msg": xxx
}
```
- 正常时 code 为 "000000"
- 异常时可自定义错误码，前端按错误码调整逻辑

## 复现步骤
1. 调用任意 API
2. 查看响应结构
