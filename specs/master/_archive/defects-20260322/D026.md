# 详情页触发 Ant Design 废弃 API 警告（labelStyle / Descriptions span）

## 现象
进入以下详情页时，浏览器控制台输出 Ant Design 警告：

### `/intent-library/:id`
1. `[antd: Descriptions] 'labelStyle' is deprecated. Please use 'styles={{ label: {} }}' instead.`
2. `[antd: Descriptions] Sum of column 'span' in a line not match 'column' of Descriptions.`

### `/dialog-profile/:id`（二次冒烟新增）
1. `[antd: Descriptions] 'labelStyle' is deprecated. Please use 'styles={{ label: {} }}' instead.`

## 期望
- 不使用已废弃的 `labelStyle` prop，改用 `styles={{ label: {} }}`
- Descriptions 组件每行的 `span` 之和应等于 `column` 值，避免布局警告

## 复现步骤
1. 登录后导航到 `/intent-library`，点击任意指令库的「详情」按钮，打开 Console 观察
2. 导航到 `/dialog-profile`，点击任意方案的「详情」按钮，打开 Console 观察

## 根因
- `labelStyle` 为 Ant Design 已废弃 prop，需改用 `styles={{ label: {} }}`
- Descriptions 在 column=3 时，某行 span 之和（置信度 1 + 模糊阈值 1 + 描述 3）为 5，与 column 不匹配，需补足或调整布局。

## 修复方案
将 `labelStyle` 替换为 `styles={{ label: { color: '...', fontWeight: 500 } }}`；为满足 column=3，在 IntentLibrary 详情中增加占位 Item，使每行 span 之和为 3。

## 修复说明
- IntentLibrary/Detail.jsx、DialogProfile/Detail.jsx：`labelStyle` → `styles={{ label: {} }}`
- IntentLibrary/Detail.jsx：增加占位 `Descriptions.Item label=" " span={1}`，描述项 `span={3}` 独占一行
