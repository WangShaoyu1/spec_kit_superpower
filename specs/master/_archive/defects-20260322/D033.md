# 对话方案模块与 PD 交互稿存在多处功能差距

## 现象
对照 `pd-dialog-profile/` 的 index 和 detail 页面，实际存在以下差距：

### 列表页 `/dialog-profile`
| PD 定义 | 实际 | 差距 |
|---------|------|------|
| Table 列: 大模型 | 不存在 | 缺失 |
| Table 列: 人设 | 不存在 | 缺失 |
| Table 列: 指令阈值 | 不存在 | 缺失 |
| Table 列: 会话超时 | 不存在 | 缺失 |
| Table 列: 绑定指令库（名称） | 仅显示「绑定库数」 | 信息不足 |
| Table 列: 更新时间 | 显示为「创建时间」 | 不一致 |
| 统计卡: 方案总数/已发布/草稿/测试中 | 方案总数/草稿/已激活/发布版本 | 名称和含义不一致 |
| 筛选器: 全部策略(指令优先/知识优先/均衡) | 不存在 | 缺失 |
| 查询/重置按钮 | 不存在 | 缺失 |
| 状态流转: draft→testing→published→archived | 仅看到「草稿」 | 流转不完整 |

### 详情页 `/dialog-profile/:id`
PD 定义了丰富的详情页功能：
- 编辑基本信息、绑定指令库、切换/编辑/新建人设
- 发布确认弹窗（校验清单、版本对比、影响范围、5 秒倒计时）
- 版本发布历史 Timeline

无法在当前冒烟测试中验证所有详情页功能。

## 期望
补齐 PD 中定义的表格列、筛选器，统一统计卡片名称与 PD 一致。

## 复现步骤
1. 登录后进入 `/dialog-profile`
2. 对照 PD 检查 Table 列、筛选器、统计卡片
3. 确认差距

## 根因
同 D031，AD/DD 未定义前端 UI 规格。DD 缺少 testing 状态。

## 修复方案
新增表格列（大模型/指令阈值/会话超时）、更新时间列、策略筛选器、查询重置按钮；统计卡对齐PD命名；发布确认弹窗增加校验清单和5秒倒计时；新增版本历史Timeline。

## 修复说明
- index.jsx: 新增 3 列、更新时间、策略筛选器、统计卡对齐、查询重置
- Detail.jsx: 发布弹窗增加校验清单+影响范围+5秒倒计时；版本历史 Timeline

## 设计回溯
DD 状态机缺少 testing 状态（AD 有），建议同步更新 dd-dialog-profile §4.1。
