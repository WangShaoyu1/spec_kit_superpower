# 手动测试 + 批量测试与 PD 交互稿存在功能差距

## 现象

### 手动测试 `/test-chat`
| PD 定义 | 实际 | 差距 |
|---------|------|------|
| 「设备上下文」按钮 | 不存在 | 缺失 |
| 新建会话弹窗（会话名称、关联方案、设备上下文预设、备注） | 仅「选择对话方案」下拉 + 「新建会话」按钮，无弹窗 | 流程简化 |
| 设备上下文配置（cooking_status、door_closed、current_temp 等） | 不存在 | 缺失 |
| 删除会话（hover 显示） | 无数据无法验证 | 待确认 |
| 调试面板详细字段（路由、指代消解、知识库命中、对话状态等） | 仅显示占位文案 | 无数据无法完全验证 |

### 批量测试 `/batch-test`
| PD 定义 | 实际 | 差距 |
|---------|------|------|
| Table 列: 达标 | 不存在 | 缺失 |
| Table 列: 平均耗时 | 不存在 | 缺失 |
| 统计卡: 批次总数/已完成/执行中/未达标 | 测试总数/运行中/已完成/平均准确率 | 「未达标」→「平均准确率」不一致 |
| 筛选器: 关联方案 | 不存在 | 缺失 |
| 筛选器: 达标状态 | 不存在 | 缺失 |
| 查询/重置按钮 | 不存在 | 缺失 |
| 新建测试两步流程(Step1 基本信息 + Step2 用例来源) | 无数据无法验证完整流程 | 待确认 |

## 期望
手动测试页面应提供设备上下文配置功能和完整的新建会话流程。批量测试页面应补齐表格列、筛选器和统计卡片。

## 复现步骤
1. 登录后进入 `/test-chat`，确认无「设备上下文」按钮
2. 进入 `/batch-test`，对照 PD 检查表格列、统计卡片、筛选器

## 根因
手动测试 UI 不在 batch-test AD/DD 中；统计卡和筛选器 UI 规格未文档化。

## 修复方案
批量测试：统计卡第4项改为未达标、新增达标/平均耗时列、关联方案/达标状态筛选器。手动测试：新增设备上下文配置 Drawer、会话创建 Modal。

## 修复说明
- BatchTest/index.jsx: 统计卡、2新列、2新筛选器、查询重置
- TestChat/index.jsx: 设备上下文 Drawer、会话创建 Modal

## 设计回溯
手动测试缺少独立 AD/DD，建议补充 ad/dd-test-chat 或并入 ad/dd-dialog-profile。
