# pd-user-mgmt: 用户管理交互原型

## 项目概述

本交互原型基于 `pd-template.md` v4.1 规范，实现用户管理模块的交互设计（角色定义 → 能力点管理 → 用户 CRUD → 权限分配）。

**技术栈**: React 18 + Ant Design 6.x (CDN UMD, 无脚手架) + Babel Standalone + Dayjs

**对应规范**: `specs/master/spec.md` v1.4，覆盖 FR: FR-001

**PD 模块 Key**: `user-mgmt`（参见 `specs/master/pd-all/pd-index.md`）

## 模块定位

- 本模块用于平台账号、角色和能力点的统一管理
- 本模块关注被管理对象是“系统用户 + 角色能力模型”，不是业务数据本身
- 本模块是其他业务模块权限收口的基础入口

## 业务价值

- **解决什么问题**：避免账号创建、角色分配、能力点管控散落在各业务模块，降低权限漂移和运维风险
- **用户是谁**：管理员（创建账号、分配角色、审视权限矩阵）
- **使用场景**：
  1. 创建 PM / tester 账号并直接授予预设角色
  2. 调整角色后预览能力点变化，确认是否影响发布、测试、监控等关键操作
- **成功标准**：管理员可在单页内完成账号开通、角色调整和权限核对

## 技术约束

1. 无脚手架：纯 CDN 引入，无 build 步骤
2. 显式 window 访问：`const antd = window.antd; const icons = window.icons;`
3. 完整解构：所有使用的组件/图标都在顶部显式解构
4. Mock 数据：全部使用静态 mock 数据，无真实 API
5. 权限判断口径以 capability 为准，不在原型中硬编码业务角色特权
