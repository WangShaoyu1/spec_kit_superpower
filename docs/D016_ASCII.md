# D016 ASCII 图（页面结构与交互）

> 基于 `specs/master/defects/D016.md` 当前定稿口径整理。  
> 目标：用 ASCII 明确页面分层、关键交互、状态流转与权限控制。

---

## 1) 页面结构总览（IA）

```text
+----------------------------------------------------------------------------------+
| SmartChef 后台                                                                   |
+----------------------------------------------------------------------------------+
         |
         +-- 指令库管理 (/intent-libraries)
               |
               +-- 指令库列表页（一级）
               |     - 新增/编辑/删除指令库
               |     - 查看库级默认阈值(intent_f1/slot_f1)
               |     - 进入「模型管理」
               |
               +-- 指令库详情页（模型管理，二级）
               |     - 模型列表（每库最多5个）
               |     - 状态：draft/training/trained/evaluating/testable/published
               |     - 操作：训练、评估、设为testable、发布、归档、恢复draft
               |     - 进入「测试页」
               |
               +-- 测试页（三级，模型维度）
                     - 单条测试（对话框式，可展开详情）
                     - 批量测试（评估任务）
                     - 评估结果列表 + 智能分析（自动生成）

         +-- 对话方案管理 (/profiles)
               - 方案可不绑定指令库
               - 若绑定某库：该库必须存在 published 模型，方案才允许发布
```

## 3) 模型状态机与互斥规则

```text
draft -> training -> trained -> evaluating -> testable -> published
  ^                                                   |         |
  |                                                   |         |
  +----------------------- 归档恢复 -------------------+---------+

补充规则:
1) 每个库同一时刻最多1个 testable
2) 每个库同一时刻最多1个 published
3) 同一模型允许同时是 testable + published
4) 从 A 切换 B 为 testable: 自动取消 A 的 testable
```

## 4) 关键交互流（E2E 业务流）

### 4.1 训练与发布主流程

```text
[库A]
  -> 导入/生成训练集(手工+LLM)
  -> 新建训练任务
  -> 产出模型M1 (trained)
  -> 发起评估任务 (evaluating)
  -> 评估完成 (testable)
  -> 人工发布(二次确认, 备注可空, 需 model_publish)
  -> M1 进入 published
  -> 对话方案绑定库A时可发布并生效
```

### 4.2 测试路径（单条 vs 批量）

```text
                +-----------------------------+
                | 指令库 -> 模型 -> 测试页     |
                +-----------------------------+
                    |                     |
                    |                     |
         [单条测试弹窗]              [批量测试任务]
         - 输入utterance             - 选择评估集
         - 返回简要结果              - 可覆盖阈值(写快照)
         - 展开查看详细响应          - 结果完成自动触发智能分析
```

## 5) 数据入口与字段口径

### 5.1 训练集（最小字段）

```text
intent_key | utterance | language | slots(json) | source(manual/llm)
```

### 5.2 评估集（全字段）

```text
intent_key | utterance | language | source(manual/llm)
expected_result | actual_result | threshold | actual_score | is_hit

说明:
- actual_result / actual_score / is_hit 可为空
- 为空字段在评估执行后由系统回填
```

## 6) 阈值与命中逻辑（与 D014 一致）

```text
输入文本
  -> 命中已发布模型(按库)
  -> 预测意图 + score
       |
       +-- score < command_threshold  或  intent == unknown
       |      -> 视为未命中
       |      -> 直接进入后续链路(知识/闲聊)
       |      -> 不跨库回退
       |
       `-- score >= command_threshold 且意图有效
              -> 指令链路继续执行
```

## 7) 权限与门禁

```text
权限点:
- model_test_manage : 管理 testable 切换 + 进入模型测试管理
- model_publish     : 执行发布动作(二次确认)

门禁:
1) 模型数 >= 5:
   - 禁止新建训练任务
   - 提示: "请先归档/删除历史模型"

2) 对话方案发布:
   - 若方案未绑定指令库: 可发布
   - 若方案绑定库且库无published模型: 禁止发布并提示
```
