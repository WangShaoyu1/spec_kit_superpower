## 反馈闭环规则
- 没有证据，不得关闭问题。
- 没有回归，不得把整改标成完成。
- 没有同步 `tasks/*.md` / `module-state.json` / 审核报告，不得宣称验收收口。
- 若规范、实现、测试三者冲突，先登记为“规范冲突”，再决定归责。
